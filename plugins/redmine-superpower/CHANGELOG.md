# Changelog — redmine-superpower

Package release notes for the **redmine-superpower** plugin. CI publishes the
section matching the plugin's `version` as the GitHub Release notes.

This is separate from the per-skill **conventions schema** version (the
`Release:` line in each `SKILL.md`, changelogged under `skills/*/CHANGELOG.md`),
which tracks onboarding-interview changes, not package releases.

## 1.0.0

- Initial marketplace release. Ships `redmine-onboarding` (setup) and
  `redmine-tracking` (runtime).
- Installable from the `samuelzamvil` marketplace (`redmine-superpower@samuelzamvil`) and as a
  direct-import zip.
